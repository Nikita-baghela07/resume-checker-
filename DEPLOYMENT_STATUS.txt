STEP 1: Push Code to GitHub (1 minute)
   $ git add .
   $ git commit -m "Ready for Render deployment"
   $ git push origin main

STEP 2: Deploy on Render (10 minutes)
   1. Go to https://render.com
   2. Click "New +" → "Web Service"
   3. Connect your GitHub repo
   4. Set these values:
      - Build command: 
        pip install -r resume-checker-/backend/requirements-deploy.txt
      - Start command:
        cd resume-checker-/backend && gunicorn -w 2 -b 0.0.0.0:8000 \
        --timeout 120 --access-logfile - run:app
      - Plan: Starter (512 MB, $7/month)
   5. Add environment variables:
      * GROQ_API_KEY = your_key
      * ENABLE_SBERT_MODEL = false (CRITICAL!)
      * ALLOWED_ORIGINS = http://localhost:5173
   6. Click "Create Web Service"

STEP 3: Monitor Deployment (5-10 minutes)
   ✓ Watch build logs
   ✓ Look for: "✅ SBERT model DISABLED [LIGHTWEIGHT MODE - 200MB saved]"
   ✓ Check: "Application startup complete"

STEP 4: Test Live API
   curl https://optiresume-ai-backend.onrender.com/docs
